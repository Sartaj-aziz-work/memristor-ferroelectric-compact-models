# Memristor and Ferroelectric Compact Models

A research repository containing compact models of memristive and ferroelectric devices implemented in Verilog-A and LTspice.

## Contents

- Verilog-A compact models
- LTspice models
- Memristor models
- Ferroelectric models
- Testbenches
- Example simulations
- Model equations
- Parameter sets
- Validation data

## Model Families

### Memristors

- Linear Drift
- Nonlinear Drift
- TEAM
- VTEAM
- Yakopcic

### Ferroelectric Models

- Landau-Khalatnikov
- Preisach
- Other phenomenological models

## Simulation Tools

- Verilog-A
- LTspice
- Python
- MATLAB
